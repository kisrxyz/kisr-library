# Kisr Library

Твоя личная библиотека книг, которые пишет Claude. Ты просишь разобрать тему, Claude отвечает книгой по главам, а приложение хранит её на телефоне: открывается мгновенно, работает без интернета, помнит, где ты остановился (с точностью до абзаца), считает время чтения, даёт отмечать абзацы и писать заметки, ставить галочки в чек-листах и проверять себя карточками. Книги лежат на твоём устройстве, а если включишь синхронизацию — ещё и в твоём приватном репозитории на GitHub, откуда их берут другие твои устройства. Своего сервера у приложения нет.

Адрес приложения: https://kisrxyz.github.io/kisr-library/

## Как установить на iPhone

1. Открой адрес приложения в **Safari** (не в Chrome и не внутри Telegram).
2. Нажми «Поделиться» → «На экран «Домой»» → «Добавить».
3. Дальше открывай Kisr Library только с экрана «Домой», как обычное приложение.

> Важно: на iPhone у установленного приложения и у вкладки Safari **разные хранилища**. Всё, что добавишь во вкладке браузера, в приложении не появится. Поэтому книги добавляй и копии восстанавливай только в установленном приложении. Если открыть сайт во вкладке, приложение само напомнит об этом.

На Android всё так же: меню браузера → «Установить приложение». Там ещё работает «Поделиться → Kisr Library» прямо из Claude.

## Как перенести книги из старой библиотеки

Все 29 книг (23 из выгрузки от 22.11 и 6 новых разборов от 23.11) и твои места чтения собраны в один файл: `migration/kisr-library-backup-migrated.json` в папке проекта на компьютере. В интернет и в git он не попадает.

1. Перешли файл себе: в Telegram «Избранное», на почту или в iCloud Drive.
2. На iPhone сохрани его в «Файлы» (в Telegram: нажми на файл → «Поделиться» → «Сохранить в Файлы»).
3. Открой **установленное** приложение → «Ещё» → «Восстановить из копии» → выбери файл.
4. Подтверди. Приложение покажет итог вроде «Добавлено 29, обновлено 0, пропущено 0».

Если старое приложение успело написать ещё разборы, выгрузи их папкой `kisr-razbory-<дата>` в папку проекта и скажи Claude Code: «влей разборы из папки … и пересобери копию». Папки с такими именами в git не попадают.

Проверь: «Дейл Карнеги» должен открыться на главе 5 «Чтобы быть интересным…». Повторное восстановление безопасно: ничего не задвоится, побеждает более свежее.

## Как добавлять книги

1. Один раз поставь скилл (см. ниже).
2. В Claude напиши: «Разбор для Kisr Library: тема». Можно добавить объём («подробно», «коротко»). Запрос можно собрать и в самом приложении: «Добавить» → «Попросить Claude».
3. Когда Claude ответит, нажми «Копировать» под ответом. Ответ целиком и есть книга, ничего вырезать не нужно.
4. В приложении: «Добавить» → «Вставить из буфера». Проверь название и раздел, нажми «Сохранить на полку».

Если приложение уже знает такую книгу, оно спросит: «Обновить» (место чтения и отметки сохранятся), «Дописать» (главы встанут в конец) или «Отдельно».

**Длинные книги.** Если Claude отдал книгу файлом `….md`, сохрани его и выбери в «Добавить» → «Выбрать файлы». Если пришла частями (`part: 1/3`, `part: 2/3`…), вставляй по очереди: приложение предложит «Дописать», и все части сложатся в одну книгу.

## Скилл для Claude

Скилл учит Claude писать книги именно в том формате, который читает приложение.

1. Возьми файл `claude-skill/kisr-library-razbor.zip` из папки проекта (или со страницы репозитория: «Download raw file»).
2. В claude.ai: «Настройки» → «Возможности» → «Навыки» → загрузить zip. Если там уже есть старый `kisr-library-razbor`, замени его новым (при необходимости сначала удали старый).
3. Убедись, что навык включён.

Подробности, что делать без раздела «Навыки», и как менять скилл: [claude-skill/README.md](claude-skill/README.md).

## Синхронизация между устройствами

Чтобы книги, места чтения и отметки были одинаковыми на телефоне и ноутбуке, приложение хранит общую копию в **твоём приватном репозитории на GitHub**. Видишь его только ты. На каждом устройстве синхронизацию нужно один раз настроить.

**Первое устройство** (то, где уже есть книги, например iPhone):

1. «Ещё» → «Синхронизация» → «Настроить».
2. Шаг 1: «Открыть GitHub». Откроется создание репозитория `kisr-library-data`. Проверь, что выбрано **Private**, и нажми «Create repository». Если репозиторий уже есть, пропусти этот шаг.
3. Шаг 2: «создать ключ». В «Repository access» выбери «Only select repositories» → `kisr-library-data`. Права (Contents: Read and write) и срок («без срока») уже заполнены. Нажми «Generate token» и скопируй ключ: GitHub показывает его один раз.
4. Вставь ключ в приложение и нажми «Подключить». Книги уйдут в репозиторий.

**Второе устройство** (ноутбук): открой https://kisrxyz.github.io/kisr-library/ → «Ещё» → «Синхронизация» → «Настроить». Шаг 1 пропусти. Создай ещё один ключ (шаг 2) или вставь тот же → «Подключить». Через несколько секунд на полке появятся все книги.

Дальше всё происходит само:

- синхронизация идёт при открытии приложения, при возврате в него, через пару секунд после правок, а после чтения — через минуту тишины или сразу, как уходишь из приложения;
- без интернета приложение работает как раньше и догоняет, когда сеть появится;
- удаление тоже синхронизируется: удалил книгу на телефоне — она пропадёт и на ноутбуке;
- оформление (тема, шрифт, скорость чтения) у каждого устройства своё;
- если книга открыта, а на другом устройстве ты ушёл в другое место, появится «Ты читал эту книгу на другом устройстве · Перейти».

Ключ хранится только на устройстве и в резервную копию не попадает. Если он перестанет работать, в «Ещё» появится «Вставить новый ключ». Не делай репозиторий открытым: тогда приложение перестанет синхронизировать. «Отключить на этом устройстве» ничего не удаляет: книги останутся и здесь, и в репозитории.

## Резервные копии

Без синхронизации книги, отметки и места чтения лежат только в памяти телефона. Если сбросить Safari, удалить приложение или потерять телефон, всё пропадёт, пока нет копии. Синхронизация переносит и удаления, поэтому копия на всякий случай полезна и с ней. Поэтому:

- раз в пару недель или после каждых 5 новых книг: «Ещё» → «Сделать резервную копию» → сохрани файл в «Файлы» или отправь себе в Telegram;
- приложение само напомнит на полке, когда пора, и это напоминание можно отложить на неделю;
- копию можно восстановить на любом устройстве: «Ещё» → «Восстановить из копии».

Файлы копий не публикуй и не клади в репозиторий: в них твои книги. Папка `migration/` и все `*backup*.json` скрыты от git.

## Обновления приложения

Когда выйдет новая версия, внизу появится тост «Доступно обновление · Обновить». Нажми «Обновить»: приложение перезапустится на новой версии. Книги и прогресс при этом не трогаются. Кнопка «Обновить приложение» есть и в «Ещё».

## Разработка

Нужен Node 24.

```
npm i                 # установить зависимости
npm run dev           # разработка: http://localhost:5173
npm test              # юнит-тесты (Vitest)
npm run typecheck     # проверка типов
npm run build         # сборка в dist/
npm run e2e           # сквозные тесты (Playwright: iPhone/WebKit и Android/Chromium)
npm run migrate       # перенос из старого приложения → migration/kisr-library-backup-migrated.json
npm run skill         # пересобрать claude-skill/kisr-library-razbor.zip
npm run icons         # PNG-иконки из assets/icon.svg
```

`npm run preview` показывает собранную версию (service worker работает только в ней). Тесты на реальных книгах сами пропускаются, если папок `migration/` и `kisr-library/` нет, например на CI.

**Выкладка:** push в ветку `main` запускает GitHub Actions: `npm ci` → тесты → сборка с `BASE_PATH=/<репозиторий>/` → публикация на GitHub Pages. Один раз в настройках репозитория включи Pages: Settings → Pages → Source: «GitHub Actions».

Где что лежит, как продолжать и что ещё не проверено на настоящем iPhone: [HANDOFF.md](HANDOFF.md). Что и почему строим: [docs/spec.md](docs/spec.md), формат книги: [docs/book-format.md](docs/book-format.md).
