# Заметки о садовых инструментах

Садовые инструменты служат дольше, если после работы их очищать от земли и протирать маслом. Это синтетический текст для проверки разбора без шапки, поэтому в нём нет ничего полезного.

## Уход
Протирать лопату ветошью после каждого использования.

## Хранение
Хранить инструменты в сухом месте.
