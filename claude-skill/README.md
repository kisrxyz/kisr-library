# Скилл Claude для Kisr Library

Скилл — это «скрипт», который ты включаешь в Claude один раз. После этого на просьбу «разбери тему» Claude отвечает готовой книгой в том формате, который понимает приложение: с шапкой, главами, карточками, заданиями с галочками и ссылками на источники. Ответ — только сама книга, без вступления и вопросов в конце, чтобы его можно было скопировать целиком.

## Что лежит в папке

- `kisr-library-razbor.zip` — скилл для загрузки в claude.ai (внутри папка `kisr-library-razbor` с файлом `SKILL.md`).
- `kisr-library-razbor/SKILL.md` — тот же скилл в открытом виде: можно прочитать и поправить.
- `project-instructions.md` — тот же текст для Claude Project, если скиллы тебе недоступны.

## Как установить

1. Скачай `kisr-library-razbor.zip` из репозитория (кнопка «Download raw file» на странице файла).
2. Открой claude.ai → «Настройки» → «Возможности» → «Навыки».
3. Загрузи zip. Если там уже есть старый скилл `kisr-library-razbor`, он заменится новым: имя то же.
4. Убедись, что навык включён.

Если «Навыки» нет: создай в Claude проект, открой «Инструкции проекта» и вставь весь текст из `project-instructions.md`. Тогда каждый ответ в этом проекте будет книгой.

## Как пользоваться

Напиши Claude в обычном чате или в приложении Claude на телефоне, например:

> Разбор для Kisr Library: как работает память

Скилл включается, когда в просьбе есть «для Kisr Library», «для библиотеки» или прямо «напиши книгу про…». Обычное «разбери тему» без этих слов Claude отработает как всегда, без формата книги. (В Claude Project с `project-instructions.md` книгой становится каждый ответ.)

Можно добавить объём и пожелания: «подробно», «коротко», «для новичка», «с планом на месяц». Если объём не назван, будет «средне–подробно» (15–30 минут чтения).

Проще всего собрать запрос в самом приложении: «Добавить» → «Попросить Claude». Выбери тему и объём, нажми «Скопировать запрос» или «Открыть Claude».

## Как добавить книгу в приложение

1. Нажми «Копировать» под ответом Claude. Весь ответ и есть книга, ничего вырезать не надо.
2. Открой Kisr Library → «Добавить» → «Вставить из буфера».
3. Проверь название и раздел, нажми «Сохранить на полку».

Если Claude отдал книгу файлом `….md` (так бывает с очень большими книгами): сохрани файл и выбери его в «Добавить» → «Выбрать файлы».

Если Claude отдал книгу частями (`part: 1/3`, `part: 2/3`, …): напиши ему «дальше», пока не придут все части, и вставляй каждую в приложение по очереди. Приложение предложит «Дописать продолжением», и главы добавятся в ту же книгу.

## Если захочешь поменять скилл

Правь только `kisr-library-razbor/SKILL.md`, затем в папке проекта выполни `npm run skill`: он пересоберёт zip и `project-instructions.md`. Новый zip заново загрузи в claude.ai.
