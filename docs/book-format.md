# Формат книги Kisr Library — контракт

Этот файл — единый источник правды для двух сторон:
- **скилл Claude** (`claude-skill/kisr-library-razbor/SKILL.md`) пишет книги ровно так;
- **приложение** (`src/core/parse.ts`) читает книги ровно так и прощает отклонения (см. «Что приложение прощает»).

Формат совместим со старым приложением (артефакт в claude.ai) и его `pack.py`: всё, что принимало оно, принимает и новое.

## Шаблон

````markdown
---
title: Название, до 70 символов
category: Раздел полки, 1–2 слова
tags: [тег, тег, тег]
summary: 1–2 законченных предложения — что даст эта книга
source: главные источники коротко
level: базовый            # необязательно: базовый | средний | продвинутый
part: 1/2                 # необязательно: только если книга пришла частями
---
Вступление без заголовка: 2–3 предложения с главной мыслью.

## Коротко
- 5–7 пунктов: вердикт, главные цифры, что делать

## Смысловой раздел (таких 3–8; в длинной книге больше)
### Подзаголовок
Текст, примеры, исследования, таблицы, цитаты через «>».

## Мифы
Если тема ими обросла: миф → что на самом деле → вердикт.

## Что делать
- [ ] шаг, который можно сделать сегодня
- [ ] …

## Оговорки
Где данные слабые и когда совет не работает.

## Шпаргалка
Всё главное на один экран.

## Карточки
```cards
Q: вопрос в одну строку
A: ответ в одну строку

Q: …
A: …
```

## Источники
- [Автор, год. Название — журнал или сайт](https://…)
````

## Правила разметки

- Шапка — первые строки текста, между двумя строками `---`. Поля — `ключ: значение`. Списки — `[a, b, c]`. Кавычки вокруг значений необязательны.
- Каждый `## ` — отдельная глава, то есть отдельный экран в читалке. Удобный размер — 300–1200 слов. Если больше, делить на несколько `## `, а внутри использовать `###`.
- Текст до первого `## ` становится главой «Вступление». Если в нём меньше 40 слов, он приклеивается к следующей главе.
- Заголовок `#` не нужен: название берётся из `title`.
- Не ставить `---` между разделами и не выделять жирным целые абзацы.
- Заголовки — по-русски: «Коротко», «Что делать», «Оговорки», «Источники».
- Таблицы — до 5–6 столбцов: на телефоне шире не читается.
- Чек-листы и планы — `- [ ]`: в приложении они отмечаются и сохраняются.
- Карточки — 8–15 пар, ответ в одну строку, в блоке ```` ```cards ````. Допустимы `Q:`/`A:`, `В:`/`О:`, `Вопрос:`/`Ответ:`.
- Метки силы доказательств: 🟢 надёжно, 🟡 перспективно, 🔴 спорно. Других эмодзи нет.
- Формулы — словами и примером на числах: LaTeX приложение не рисует.
- Ссылки — обычные Markdown-ссылки, они открываются во внешнем браузере.

## Объёмы

| Запрос | Слов | ≈ чтения (180 слов/мин) |
|---|---|---|
| Коротко | 600–1200 | 4–7 мин |
| Средне | 2000–3500 | 11–20 мин |
| Подробно | 4000–6000 | 22–33 мин |
| Книга | 6000–9000 | 33–50 мин |

## Книга частями

Если книга не помещается в один ответ, каждая часть начинается со своей шапки с **тем же `title`** и полем `part: N/M`. Приложение предложит «Дописать продолжением», и главы части 2 добавятся после глав части 1. Вступление без заголовка во второй и следующих частях не нужно.

## Несколько книг за раз

В одну вставку или файл можно положить несколько книг подряд. Каждая начинается со своей шапки `---` / `title:` с начала строки.

## Что приложение прощает (нормализация)

Повторяет `normalizeMd` из старого приложения:
1. BOM, `\r\n`, обёртка всего текста в ```` ```markdown … ``` ```` убираются.
2. Текст до шапки (например, «Вот разбор:») отбрасывается, если шапка начинается в первых 600 символах.
3. Нет шапки: название берётся из `# Заголовка`, из строки `**Жирный заголовок**` перед первой главой или из имени файла. Иначе — «Без названия». Раздел — «Разное». Описание собирается из первого содержательного абзаца.
4. `# ` внутри текста становятся `## `. Строка «Источники:» превращается в заголовок `## Источники`.
5. Нет ни одного `## `: глава из `###`, если они есть, иначе из строк-абзацев вида `**Заголовок**`. Если и этого нет, весь текст — одна глава «Текст».
6. Английские заголовки переводятся: TL;DR/Summary → Коротко, Key findings → Главное, Details → Подробно, Recommendations → Что делать, Caveats → Оговорки, Sources/References → Источники, Conclusion → Итог, Next steps → Что сделать, Overview/Introduction → Обзор.
7. `---` в начале и конце глав срезаются.
8. Глава длиннее 1200 слов, в которой есть `###`, делится по `###` (мелкие куски склеиваются, пока не наберут около 250 слов, максимум 1000).

## Подсчёты

- Слова: `/[\p{L}\p{N}]+/gu`.
- Минуты: `max(1, ceil(слова / скорость))`, скорость по умолчанию 180 слов/мин.
- Карточки: число строк `^\s*(Q|В)\s*:` (по всей книге).
- Задачи: число строк `^\s*[-*] \[[ xX]\]`.
